# Carpeta para el repositorio del profesor

Clona aquí el repositorio de ejemplos del módulo (sin hacer *commits* en su rama `main`):

```bash
git clone URL-DEL-REPOSITORIO-DEL-PROFESOR www/dwcs-profe
```

Si la carpeta no está vacía, `git clone` se niega: borra este README antes de clonar.

Se ve en http://dwcs-profe.localhost:8080
