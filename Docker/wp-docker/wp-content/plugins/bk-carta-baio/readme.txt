Plugin de ejemplo para aprender a desarrollar en WordPress.

== Description ==

* Tipo de contenido "Plato" con la taxonomía "Tipo de plato".
* Precio en una metacaja (con nonce y saneado).
* Shortcodes [carta_baio], [carta_baio tipo="postre"] y [precio_plato].
* Página Ajustes > Carta Baio (Settings API).
* Ruta REST: /wp-json/baio/v1/carta
